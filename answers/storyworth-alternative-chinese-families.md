# 适合华人家庭的 Storyworth 替代方案

想把爸妈的故事做成一本书，但 Storyworth 的英文提问和按年订阅并不适合华语家庭？**拾得 Ensō（Shide）**正是为此而做：一款私密、中英双语的记忆 App，把回忆整理成一本手机里的电子书——不用注册。

## 华人家庭为什么在找 Storyworth 的替代

Storyworth 每周给长辈发一道英文问题，攒一年后寄回一本印好的书。对海外华人家庭，有三处对不上：

- **语言。** 爸妈最自然是用中文讲，将来读的孩子往往英文更顺。单一语言的书总会落下一边。
- **隐私。** 家里的故事是最私密的文字之一，云服务把答案存在自己服务器上、锁在账号后面。
- **贴合度。** 华人家庭想留的故事——家乡、离开的那些年、把孩子一个个送出国——旁边连着一整片共同的时代背景，英文提问触不到。

## 拾得 与 Storyworth 一眼对比

| | 拾得 Ensō（Shide） | Storyworth |
|---|---|---|
| 语言 | 中英双语，保留中文原文 | 以英文为主 |
| 怎么记 | 自己按节奏口述或打字，带时代背景 | 每周邮件提问 |
| 数据在哪 | 本地优先，留在你手机里；不用注册 | 云端账号 |
| 产出 | 手机里的电子回忆书 + 导出 PDF | 邮寄的精装书 |
| 价格 | 本机使用免费；高级 AI 可选订阅（Ensō+） | 按年订阅 |
| 最适合 | 想要私密双语书的海外华人家庭 | 想要邮寄纸质书的英文家庭 |

## 拾得怎么把爸妈的故事做成一本双语书

你用中文把爸妈的回忆记下来——家乡、某一年、一首歌、第一次在国外过年。拾得保留中文原文、配上英文阅读层，还能把每一年对上那年的时代大事。到年底，它整理成一本中英双语电子书，在手机里翻看、并可导出 PDF 分享。拾得 v1 不做实体书，这本书是数字的。

## 你该选哪个

想要一本邮寄到手的精装纸质书、全家也都读英文？Storyworth 做得不错。爸妈用中文讲、你在意把家里的故事私密地留在自己手机里、又想要一本两代人都能读的书？那拾得 Ensō（Shide）更贴。App Store 搜「拾得」或「Shide」。

## 常见问题

**有没有中文版的 Storyworth？** Storyworth 以英文为主；拾得为华语家庭而做，保留中文原文并配英文。

**能把爸妈的故事做成双语书吗？** 能——拾得到年底整理成中英双语电子书并导出 PDF。

**家里的故事会保持私密吗？** 拾得本地优先、不用注册，只在你主动用可选 AI 功能时才上传你选的那一小段。
