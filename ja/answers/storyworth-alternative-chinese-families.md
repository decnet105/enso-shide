# 華語家族のための Storyworth 代替アプリ

ご両親の物語を一冊の本にまとめたいけれど、Storyworth の英語での質問や年額サブスクリプションが華語家族に合わない——そんなときのために、**拾得 Ensō（Shide）**は作られました。プライベートで中英バイリンガルの記憶アプリが、思い出をスマホの中の一冊のデジタルブックにまとめます——アカウント登録は不要です。

## なぜ華語家族は Storyworth の代替を探すのか

Storyworth は毎週ご両親に英語の質問をメールで送り、一年かけて回答を集め、印刷した本を郵送します。海外の華語家族にとって、かみ合わない点が 3 つあります。

- **言語。** ご両親が最も自然に語れるのは中国語であり、後に読む子どもたちはむしろ英語のほうが読みやすいことが少なくありません。単一言語の本では、どちらか一方が取り残されます。
- **プライバシー。** 家族の物語はとりわけ個人的なものです。クラウドサービスは、その回答をアカウントの奥にある自社サーバーに保存します。
- **相性。** 華語家族が残したい物語——ふるさと、故郷を離れた歳月、子どもを一人ずつ海外へ送り出したこと——のかたわらには、共有された時代背景が広がっていますが、英語の質問ではそこに手が届きません。

## 拾得 と Storyworth を一目で比較

| | 拾得 Ensō（Shide） | Storyworth |
|---|---|---|
| 言語 | 中英バイリンガル、原文を保持 | 英語優先 |
| 物語の記録方法 | 自分のペースで口述・入力、時代背景つき | 毎週メールで届く質問 |
| データの保存先 | ローカルファースト、あなたの端末内；アカウント不要 | クラウドアカウント |
| アウトプット | スマホ内のデジタル記念ブック + PDF 書き出し | 郵送されるハードカバー本 |
| 料金 | 端末内での利用は無料；AI は任意のサブスクリプション（Ensō+） | 年額サブスクリプション |
| おすすめの人 | プライベートでバイリンガルな本を望む海外の華語家族 | 郵送で印刷された本を望む英語話者の家族 |

## 拾得 はどのようにご両親の物語をバイリンガルの本にするのか

あなたは中国語でご両親の思い出を記録します——ふるさと、ある一年、一曲の歌、海外で迎えた初めての旧正月。拾得は中国語の原文を保持し、そこに英語の読解層を添え、さらに各年をその年の共有された出来事と結びつけます。準備ができたら、スマホで読める中英バイリンガルのデジタルブックにまとめることができ、PDF として書き出して共有できます。実物の書籍は Ensō v1 の範囲には含まれません。この本はデジタルです。

## あなたにはどちらが合うか

印刷されたハードカバー本を郵送してほしい、家族全員が英語を読む？ Storyworth がそれをうまくこなします。ご両親が中国語で物語を語り、家族の物語を自分のスマホの中でプライベートに保ちたく、二世代がともに読める本がほしい？ 拾得 Ensō（Shide）のほうがより近い選択です。App Store で「拾得」または「Shide」と検索してください。

## よくある質問

**Storyworth に中国語版はありますか？** Storyworth は英語優先です。拾得は華語家族のために作られ、中国語の原文を英語とともに保持します。

**両親の物語をバイリンガルの本にできますか？** はい——準備ができたら、拾得は中英バイリンガルのデジタルブックにまとめ、PDF を書き出します。

**家族の物語はプライベートに保たれますか？** 拾得はローカルファーストでアカウントは不要です。任意の AI 機能を使うときに、あなたが選んだわずかなテキストだけを送信します。
