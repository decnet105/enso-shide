## 1. 总体设计与系统架构 (System Overview & Architecture)

拾得 (ENSŌ SHIDE) 作为面向全球华人家庭的“本地优先、一生传家书与时间考古”平台，通过三大交互与视觉模块构建起从公域文化记忆到私域家庭传记的闭环：

```
+-----------------------------------------------------------------------------------+
|                            拾得 ENSŌ SHIDE 体验闭环                               |
+-----------------------------------------------------------------------------------+
|  [1. 真实成书展区 (Look-Book)]                                                   |
|      - 1 张大封面 + 6 大真实双页跨页排版 (金曲/心象/秘境/信物/红土/年谱)          |
|      - 建立真实出版物高级杂志质感与端侧离线 A4 矢量排版认知                        |
|                                                                                   |
|  [2. 47 年时空显影机 (1980–2026 Chronoscope)]                                    |
|      - 47 年传统年色 (梅子青/茜红/海棠/琥珀...) + 4000+ 华语文化公域坐标          |
|      - 沈拾诙谐手记 (去 AI 味、幽默调侃、人间观察)                                |
|      - 一句话显影个人记忆 -> 4K 宣纸《时代印笺》长图导出                          |
|                                                                                   |
|  [3. 时代回声 · 时空留言墙 (Spacetime Message Wall)]                              |
|      - 自动打 Tag (年代 #1998千禧前夜 / 事件 #EV-1998-MODEM / 实体 #周杰伦...)    |
|      - 点击任意 Tag 即时过滤同类记忆，形成全球华人共鸣流                         |
|      - 红线安全过滤治理 (严格过滤政治/负面/黑暗/违禁)                             |
|      - ❤️ 钤印共鸣互动与持久化存储                                                |
+-----------------------------------------------------------------------------------+
```

### 2.2 沈拾手记语言准则 (Social Reply Voice)
遵循 `social-reply-voice` 技能库准则，彻底去除“AI 味”：
- **禁止词**：绝不使用“头皮发麻”、“起鸡皮疙瘩”、“让人感动落泪”、“一口气看完”、“不仅...而且...”、“让我们一起铭记”。
- **提倡口吻**：具体细节（铅笔倒带、5毛钱冰棍、Modem杀猪声、显卡风扇）、诙谐反讽（“老外通宵看西游记，腰疼也是真的疼”）、人间观察者的从容与温润。

## 3. 时空留言墙与智能标签体系 (Spacetime Wall & Auto-Tagging)

### 3.1 自动实体提取与打标算法 (`extractTags`)
当用户输入一段个人回忆时，系统自动提取 3 维标签：
1. **年份维度**：如 `#1998千禧前夜`、`#1988慢车时代`、`#2024回望传承`
2. **事件编码维度**：如 `#EV-1998-MODEM`、`#EV-2008-BJO`
3. **实体关键字匹配（地点/人物/物候/情绪）**：
   - 地点：`#北京`, `#上海`, `#广州`, `#深圳`, `#香港`, `#台北`, `#温哥华`, `#多伦多`, `#纽约`, `#伦敦`, `#老弄堂`, `#家属院`, `#网吧`
   - 人物/文化符号：`#周杰伦`, `#Beyond`, `#张国荣`, `#王菲`, `#小虎队`, `#费翔`, `#孙燕姿`, `#五月天`, `#黑神话`
   - 物候道具：`#小霸王`, `#二八大杠`, `#卡带`, `#随身听`, `#粮票`, `#红白机`, `#诺基亚`, `#MP3`, `#绿皮车`
   - 场景与共鸣：`#高考`, `#毕业季`, `#异地恋`, `#通宵`, `#下雪`, `#过年`, `#老照片`

### 3.2 交互过滤与联动 (Interactive Filtering)
- 顶部提供常用热门标签胶囊（Pills），用户点击任意卡片上的 `#标签`，留言墙将立即平滑过滤出所有携带该标签的历史留言。
- 提供“全部时空”与“🔥 最多共鸣（Hot）”排序切换。
- 提供“❤️ 钤印共鸣”点赞功能，点赞数自动累加并持久化存储在 `localStorage.shide_spacetime_wall`。

## 4. 红线内容治理与合规拦截机制 (Red-line Governance)

为了确保时空留言墙始终保持温润、积极、面向华人文化生活记忆的纯净调性，系统部署了端侧与服务端双重红线过滤算法 (`checkRedline`)：

### 4.1 拦截类别与规则
1. **政治与敏感话题**：涉及政治领导人、政党争端、意识形态攻击、领土分裂等。
2. **负面、极端与消极暗黑言论**：涉及自残、自杀、绝望极端宣泄、人身攻击、仇恨煽动。
3. **低俗与商业垃圾广告**：涉黄、涉赌、涉毒、微商推销、代孕借贷。

### 4.2 拦截反馈与用户体验
- 当用户在输入框键入包含敏感词汇的内容时，显影机下方以琥珀色温和提示：  
  `⚠️ 内容包含敏感或违规词汇，时空显影机仅记录生活琐事与文化温情，请换个温暖的角度记录吧。`
- 拦截不会封禁用户，而是引导用户重新聚焦家庭、童年、朋友、老物件等温暖的回忆瞬间。

## 7. 维护与后续扩展建议 (Maintenance & Roadmap)

1. **后端数据库同步**：当前留言墙采用本地 `localStorage` 配合 Seed 种子数据运行。后续版本可将 `createWallPost` 接入 Supabase / Firebase / Cloudflare D1，实现全网多设备实时同步。
2. **多语言沈拾手记**：目前繁体、英文、日文版主站已预留多语言架构，后续可逐步翻译 `assets/chronoscope-data.js` 中的 47 年手记为地道的英文与日文回帖风格。
3. **iOS 端侧同步**：将 `assets/chronoscope-data.js` 中的 47 年数据直接编译为 Swift 的 `struct ChronoscopeYear`，供 iOS App 2.0 端侧离线调用。
