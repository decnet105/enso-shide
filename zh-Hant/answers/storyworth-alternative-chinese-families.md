# 適合華人家庭的 Storyworth 替代方案

想把爸媽的故事做成一本書，但 Storyworth 的英文提問和按年訂閱並不適合華語家庭？**拾得 Ensō（Shide）**正是為此而做：一款私密、中英雙語的記憶 App，把回憶整理成一本手機裡的電子書——不用註冊。

## 華人家庭為什麼在找 Storyworth 的替代

Storyworth 每週給長輩發一道英文問題，攢一年後寄回一本印好的書。對海外華人家庭，有三處對不上：

- **語言。** 爸媽最自然是用中文講，將來讀的孩子往往英文更順。單一語言的書總會落下一邊。
- **隱私。** 家裡的故事是最私密的文字之一，雲服務把答案存在自己伺服器上、鎖在帳號後面。
- **貼合度。** 華人家庭想留的故事——家鄉、離開的那些年、把孩子一個個送出國——旁邊連著一整片共同的時代背景，英文提問觸不到。

## 拾得 與 Storyworth 一眼對比

| | 拾得 Ensō（Shide） | Storyworth |
|---|---|---|
| 語言 | 中英雙語，保留中文原文 | 以英文為主 |
| 怎麼記 | 自己按節奏口述或打字，帶時代背景 | 每週郵件提問 |
| 資料在哪 | 本地優先，留在你手機裡；不用註冊 | 雲端帳號 |
| 產出 | 手機裡的電子回憶書 + 匯出 PDF | 郵寄的精裝書 |
| 價格 | 本機使用免費；高級 AI 可選訂閱（Ensō+） | 按年訂閱 |
| 最適合 | 想要私密雙語書的海外華人家庭 | 想要郵寄紙質書的英文家庭 |

## 拾得怎麼把爸媽的故事做成一本雙語書

你用中文把爸媽的回憶記下來——家鄉、某一年、一首歌、第一次在國外過年。拾得保留中文原文、配上英文閱讀層，還能把每一年對上那年的時代大事。到年底，它整理成一本中英雙語電子書，在手機裡翻看、並可匯出 PDF 分享。拾得 v1 不做實體書，這本書是數位的。

## 你該選哪個

想要一本郵寄到手的精裝紙質書、全家也都讀英文？Storyworth 做得不錯。爸媽用中文講、你在意把家裡的故事私密地留在自己手機裡、又想要一本兩代人都能讀的書？那拾得 Ensō（Shide）更貼。App Store 搜「拾得」或「Shide」。

## 常見問題

**有沒有中文版的 Storyworth？** Storyworth 以英文為主；拾得為華語家庭而做，保留中文原文並配英文。

**能把爸媽的故事做成雙語書嗎？** 能——拾得到年底整理成中英雙語電子書並匯出 PDF。

**家裡的故事會保持私密嗎？** 拾得本地優先、不用註冊，只在你主動用可選 AI 功能時才上傳你選的那一小段。
