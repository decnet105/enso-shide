# 把華人共同的文化記憶，廣泛地傳播、分享給未來的一代

「拾得」把 1980 年至今的歌、影視、書、遊戲與時代大事，整理成幾代華人共同的文化座標；你也可以在這裡寫下走過的歲月、當下的生活與未來的期許，彙編成中英雙語的歲月書。App 堅持本地優先，無帳號、零上傳。我們正在打磨 AI 漫劇與短劇，探索用全新的形式，把這份記憶廣泛地傳播、分享給未來的一代。

## 為什麼做拾得

許多海外華語家庭用中文記住一生，卻很難把這些經歷完整交給以英文為主的下一代。拾得圍繞原文、英文內容和可匯出的數字成書組織資料，讓記錄不止停在資訊流裡。

- 回憶、照片、地點和心象進入端上私域模型。
- 1980-2026 華語文化座標作為公共背景，只讀下發。
- 本機成書路徑使用 UIGraphicsPDFRenderer 生成 A4 PDF。
- 公共文化內容與未來郵件屬於聯網路徑；線上 AI 整理與成書屬 Ensō+ 可選訂閱，僅在你主動觸發時聯網。

## 現在可以被程式碼證明的能力

| 能力 | 當前實現 | 公開表述 |
| --- | --- | --- |
| 私域記憶 | SwiftData Memory / Profile / Keepsake | 本地優先 |
| 紙面成書 | 端上 A4 PDF 渲染 | 本機可生成 |

| 陪聊 | 本地 ConversationGraph | v1 本機路徑 |
| 賬戶 | 公開消費路徑免登入 | 無需 Ensō 賬戶 |
